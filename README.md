# 煤省向绿：山西转型的两条曲线

独立数据新闻网页。保留图表固定、滚动切换年度高亮、文字逐段显现和可展开底表。

在线作品：https://xixinn-bit.github.io/shanxi-green-story/

## 本地查看
直接用现代浏览器打开 index.html。图表、样式、交互和来源文字全部内置，无外部运行依赖；访问来源原文需联网。
本地查看无需启动服务，不依赖可画。

## GitHub Pages
将本目录内容放在仓库根目录，在仓库 Settings → Pages 选择 Deploy from a branch、main 分支、/(root)，保存。
部署完成后使用 Pages 返回的网址访问。上传仓库本身不等于网站已经发布。

## 效果验收
在实际网页中检查：年度变化区图表固定；向下和向上滚动分别更新2021—2025年高亮；文字进入视口后显现；来源锚点和数据表展开正常。
手机竖屏采用上方固定图表、下方滚动年份的布局。开启系统“减少动态效果”时不播放文字动效。

## 数据与使用说明
页面内列有原始统计公报、资料时间、指标单位、计算口径与可点击来源。另附 data/ 数据文件。
本作品为公开资料案头调研，无虚构实地采访。AI辅助资料整理、初稿、计算和排版。提交前请补充真实作者、班级与实际分工。
独立网页为正式展示版本；此前可画转换版不作为交互验收依据。
